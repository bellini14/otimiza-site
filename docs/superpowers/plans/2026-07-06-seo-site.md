# SEO do site Otimiza — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar e verificar as 18 melhorias de SEO solicitadas em todas as páginas públicas do site Otimiza.

**Architecture:** Um catálogo central descreverá metadados por rota e um componente React sincronizará o `head` durante a navegação da SPA. Utilitários compartilhados gerarão URLs absolutas e dados estruturados; arquivos públicos e configuração Vercel cobrirão crawlers, HTTPS e compressão.

**Tech Stack:** React 19, React Router 7, Vite 8, Vitest, Testing Library, ESLint e Vercel.

---

## Estrutura de arquivos

- Criar `src/seo/siteMetadata.js`: identidade confirmada, origem pública, catálogo de rotas e helpers.
- Criar `src/seo/SeoHead.jsx`: sincronização idempotente do `head`.
- Criar `src/seo/SeoHead.test.jsx`: testes dos metadados e navegação.
- Criar `src/seo/seoAudit.test.jsx`: auditoria semântica das páginas públicas.
- Criar `scripts/generate-seo-files.mjs`: geração determinística de robots e sitemap.
- Criar `scripts/generate-seo-files.test.js`: testes dos arquivos para crawlers.
- Modificar `src/App.jsx`: associar metadados às rotas.
- Modificar páginas/componentes somente onde auditorias de H1, headings, alt, conteúdo e links falharem.
- Modificar `index.html`: defaults seguros, idioma e favicon.
- Modificar `package.json`: executar geração SEO antes do build.
- Modificar `.env.example`: documentar `VITE_SITE_URL`.
- Modificar `vercel.json`: HTTPS/cabeçalhos suportados sem quebrar o rewrite da SPA.
- Criar/atualizar `public/robots.txt` e `public/sitemap.xml` por script.
- Modificar `README.md`: documentar domínio e verificação da compressão gerenciada pela Vercel.
